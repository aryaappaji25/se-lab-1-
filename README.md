# Software Engineering – Lab 1
## Self-Service Coffee Kiosk System

This folder contains the Lab 1 deliverables for the Self-Service Coffee Kiosk System.

### Files
- `PES1UG24AM053_UseCase_Diagram.png` — UML use-case diagram.
- `PES1UG24AM053_Requirements_Table.docx` — functional and non-functional requirements table.
- `PES1UG24AM053_UseCase_Flow.pdf` — UC-04 (Make Payment) main success scenario and alternate payment-declined flow.

### Use cases shown in the diagram
1. Select Coffee Type (UC-01)
2. Choose Size (UC-02)
3. Add Add-ons (UC-03)
4. Make Payment (UC-04)
5. Print Receipt (UC-05)
6. Update Menu (UC-06)
7. Refill Ingredients (UC-07)
8. View Sales Report (UC-08)

### Actors
- Customer
- Payment Gateway
- Admin
